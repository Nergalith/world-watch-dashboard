How The Map Stays Current

Sources And Notes

World Conflict Tracking uses open public signals where possible and falls back to curated watch areas when live feeds are unavailable. It is built for fast scanning, source discovery, and basic situational awareness.

Live

GDELT Conflict Signals

A scheduled GitHub job pulls recent public article signals for conflict, military activity, border incidents, unrest, airstrikes, and insurgency topics.

Live

Curated Conflict Fallback

When public feeds fail or rate-limit, the map falls back to curated globally relevant conflict watch areas instead of going empty.

Demo

Clickable Map Markers

Each marker opens a short brief and, when the feed provides it, a public source link for verification.

Demo

Conflict Categories

The feed groups items into conflict, military, unrest, and infrastructure security categories for quick filtering.

Planned

Better Source Mix

Future public layers can add government advisories, humanitarian updates, sanctions notices, and verified regional monitors.

Note

Public Data Disclaimer

Open-source feeds can be delayed, duplicated, incomplete, or noisy. World Conflict Tracking is situational awareness, not emergency guidance.
